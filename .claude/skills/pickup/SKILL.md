# pickup — 인계 수신

세션 시작 시 실행한다. 아래 순서를 그대로 따른다.

## 1. 원격 동기화

```
git fetch --all --prune
git status
```

- **미커밋 변경이 있으면 여기서 멈춘다.** 변경 파일을 나열해 보고하고 사용자 지시를 기다린다.
  임의로 `stash`, `checkout --`, `reset`, 폐기하지 않는다.
- 작업 트리가 깨끗하면 `git pull --ff-only` 를 실행한다.
- fast-forward 가 불가능하면 **멈추고 보고한다.** 자동 머지·리베이스를 하지 않는다.

## 2. memory.md 읽기

`memory.md` **전체**를 읽는다. 일부만 읽거나 요약된 내용에 의존하지 않는다.

## 3. 실제 git 상태와 대조

"현재 상태" 블록의 **브랜치 / 마지막 커밋 / 작업 트리 상태**를 실제 git 출력과 비교한다.

불일치가 있으면 **먼저 불일치를 보고**하고, `git log --oneline -20` 으로 memory.md 에 기록되지 않은 커밋을 확인한다.

## 4. 보고

아래 형식으로 간결히 보고한다.

```
인계받음: <어느 머신 / 언제의 기록인지>
진행 중:  <진행 중인 작업>
미해결:   <미해결 이슈>
불일치:   <memory.md 와 실제 git 상태의 차이. 없으면 "없음">
다음 할 일:
  1. ...
  2. ...
```

"다음 할 일"은 `memory.md` 의 "다음 머신에서 할 일" 항목을 **그대로 옮긴다.** 임의로 추가·해석·재정렬하지 않는다.

## 5. 대기

보고 후 **작업을 시작하지 않는다.** 사용자의 지시를 기다린다.
