# 실차 테스트 규칙

실차(실제 차량)와 같은 로컬 네트워크에 있는 머신에서만 실차 테스트를 수행한다.

## 커밋 위생

현장에서만 유효한 임시 값은 **`main` 에 머지하지 않는다.**

머지 금지 대상:
- 고정 IP, 포트 등 현장 하드코딩 접속 정보
- 하드코딩 좌표
- 현장에서 맞춘 튜닝 상수
- 주석 처리한 안전 로직

현장 작업은 별도 브랜치에서 한다. 브랜치 이름 규칙:

```
field/YYYY-MM-<장소>
```

로그·덤프·레코딩 파일은 **커밋하지 않는다.** 결론만 `memory.md` 에 남긴다.

## 환경 값 위치

| 값 | 위치 |
| --- | --- |
| 실차 IP·포트·시리얼 포트명 | `CLAUDE.local.md` 및 `.env` |
| 머신별 저장소 경로, 실행 환경 | `CLAUDE.local.md` |
| 공통 기본값 | 리포지토리 설정 파일 |

- **소스에 하드코딩하지 않는다.**
- `.env` 는 읽지 않는다. 값이 필요하면 사용자에게 묻는다.
- 비밀번호·토큰·API 키는 `.env` + `dotenv` 로만 다룬다.
